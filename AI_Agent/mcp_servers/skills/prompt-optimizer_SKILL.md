# Prompt Optimizer Skill

## 핵심 역할 및 실행 원칙
1. **전문가 프레임워크 즉시 적용**: 사용자의 요청(예: "가성비 좋은 선풍기 구매하는 법")을 분석하여, 단순 답변이 아닌 전문가 페르소나, 핵심 비교 기준표, 상황별 맞춤 추천 등 깊이 있는 구조로 최적화합니다.
2. **불필요한 메타 설명 배제**: "제가 프롬프트를 개선했습니다", "이 코드를 복사해서 AI에게 다시 붙여넣으세요" 같은 장황하고 불필요한 안내를 생략합니다.
3. **완성형 결과물 즉시 도출**: 개선된 고성능 프롬프트의 지침을 AI가 곧바로 직접 수행하여, 사용자가 실제로 얻고자 하는 **최종 완성본(가이드, 분석표, 추천안 등)**을 즉시 제공합니다.
