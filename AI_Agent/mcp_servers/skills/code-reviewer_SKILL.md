# Code Reviewer Skill

## 개요
제공된 소스 코드를 심층 분석하여 잠재적 버그, 성능 병목, 보안 취약점을 식별하고 클린 코드(Clean Code) 작성을 돕습니다.

## 실행 지침 (Instructions)
1. **정밀 정적 분석 & 이슈 분류**:
   - 식별된 이슈를 심각도 태그로 명확히 구분합니다:
     - `[🚨 Critical]`: 프로그램 충돌, 치명적 버그, 보안 취약점
     - `[⚠️ Warning]`: 잠재적 오류, 예외 처리 미흡, 성능 병목
     - `[💡 Optimization]`: 가독성 개선, 표준 코딩 컨벤션(PEP 8 등), 리팩토링 제안
2. **Before & After 코드 블록 제공**:
   - 문제 코드(Before)와 개선된 코드(After)를 diff 또는 명확한 코드 블록으로 제시합니다.
3. **논리적 개선 근거 설명**:
   - 단순 수정이 아닌, 왜 이렇게 변경해야 하는지 기술적 이유를 간결하고 명확하게 서술합니다.
