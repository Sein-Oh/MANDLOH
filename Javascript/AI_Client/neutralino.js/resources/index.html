💬 1. 대화 및 세션 관리
왼쪽 사이드바에서 대화방을 관리하고 새로운 대화를 시작할 수 있습니다.
• 사이드바 열기/닫기 (☰): 채팅창 상단 좌측의 삼선(햄버거) 버튼을 클릭하여 사이드바를 숨기거나 다시 펼칠 수 있습니다.
• + 새 대화 시작: 대화 이력이 로컬에 영구 저장되는 새로운 대화방을 생성합니다. 첫 메시지에 따라 방 제목이 자동 생성됩니다.
• ⚡ Zero-Shot 대화 (휘발성): 이전 대화 컨텍스트나 파일 이력이 저장되지 않는 단발성 질의응답 모드입니다. 빠른 질의나 테스트에 적합합니다.
• 대화방 관리: 사이드바 대화방 목록에서 방 제목 더블클릭으로 이름 수정(✏️) 또는 삭제(🗑️)가 가능합니다.
• 사이드바 너비 조절: 사이드바 우측 경계선을 마우스로 드래그하여 원하는 너비로 자유롭게 조절할 수 있습니다.
⚡ 2. 단축어 기능 (@호출명령어)
자주 사용하는 긴 문장, 역할 지침, 프롬프트 템플릿을 단축어로 등록하여 대화창에서 간편하게 불러올 수 있습니다.
• 단축어 등록: ⚙️ 환경 설정 ➔ ⚡ 단축어 설정 (@) 탭에서 새 단축어를 등록합니다.
• 빠른 설정 바로가기: 대화창에 @만 입력하고 전송 버튼을 누르면 단축어 설정 팝업이 즉시 열립니다.
• @ 자동완성: 대화창에 @를 입력하면 등록된 단축어 목록이 팝업으로 표시되며, 키보드 방향키와 Enter/Tab으로 선택할 수 있습니다.
• 자동 치환 전송: 메시지 안에 @단축어를 포함하여 전송하면 설정된 실제 본문으로 자동 치환되어 전송됩니다.
예시: 단축어 날씨 = 오늘 서울의 날씨를 알려줘.
➔ "안녕하세요? @날씨" 전송 시 ➔ "안녕하세요? 오늘 서울의 날씨를 알려줘." 로 치환
🔌 3. MCP 도구 연동 및 슬래시(/) 직접 호출
FastMCP 기반의 외부 도구(파일시스템, 스킬 실행 등)를 연동하여 모델이 도구를 사용하거나 사용자가 직접 호출할 수 있습니다.
• 서버 등록 및 연결: ⚙️ 환경 설정 ➔ 🔌 MCP 서버 탭에서 HTTP 또는 SSE 방식의 엔드포인트를 등록하고 체크박스를 켜 연결합니다.
• 빠른 설정 바로가기: 대화창에 /만 입력하고 전송 버튼을 누르면 MCP 서버 설정 팝업이 즉시 열립니다.
• 슬래시(/) 자동완성: 대화 입력창에 /를 입력하면 사용 가능한 모든 MCP 도구 목록이 나타납니다.
• 도구 직접 실행: /도구명 [인자...] 형식으로 입력하여 전송하면 LLM 추론을 거치지 않고 해당 도구가 즉시 실행되며 결과가 출력됩니다.
• LLM 자동 도구 호출 (Function Calling): 일반 질문 시에도 모델이 스스로 판단하여 필요한 MCP 도구를 호출하고 결과를 종합하여 답변합니다.
🧠 4. 시스템 프롬프트 (System Prompt)의 역할과 활용법
시스템 프롬프트는 AI에게 역할(페르소나), 답변의 어조/형식, 행동 규칙 및 제약사항을 부여하는 최상위 기본 지침입니다.
📌 시스템 프롬프트의 핵심 역할:
• 전문가 페르소나 부여: 특정 분야의 전문가(예: 시니어 개발자, 번역가, 법률 자문 등)로서 답변하도록 유도합니다.
• 출력 형식 및 제약 강제: 마크다운 표(Table), JSON 형식, 코드 블록 주석 포함, 불필요한 사족 제거 등을 엄격히 통제합니다.
• 일관된 톤앤매너 유지: 한국어 존댓말 고정, 친절한 어조 또는 간결하고 냉철한 기술 문서 스타일 등을 지정합니다.
⚙️ 설정 및 적용 방법:
• 전역 기본 시스템 프롬프트: ⚙️ 환경 설정 ➔ 🤖 LLM 설정에 입력하면 모든 새 대화 및 Zero-Shot 대화에 기본으로 자동 적용됩니다.
• 대화방별 개별 프롬프트: 채팅창 상단의 ⚙️ 시스템 프롬프트 버튼을 눌러 현재 방에만 특화된 지침을 설정할 수 있습니다. (전역 기본값을 덮어씁니다)
💡 유용한 실전 프롬프트 예시:
• [코딩/개발] "당신은 15년 차 시니어 풀스택 개발자입니다. 불필요한 서론/결론은 생략하고 실제 동작하는 클린 코드와 핵심 설계 설명 위주로 답변하세요."
• [3줄 요약 & 표] "모든 질문에 대해 핵심을 3개의 글머리기호로 요약하고, 세부 사항은 마크다운 표로 깔끔하게 정리해 주세요."
• [도구 적극 활용] "사용자의 질문에 답변할 때 연동된 MCP 도구를 적극적으로 호출하여 정확한 사실에 기반해 답변하세요."
📦 5. 대화 압축 & 컨텍스트 최적화
컨텍스트 길이를 효율적으로 관리하고 토큰 비용을 최적화할 수 있습니다.
• 📦 대화 압축하기: 대화가 길어졌을 때 상단 버튼을 누르면 최근 5개 메시지를 제외한 이전 대화를 AI가 핵심만 1개의 요약 카드로 압축하여 컨텍스트 낭비를 줄입니다.
• 🗑️ 대화 비우기: 현재 대화방의 메시지 내역만 깨끗하게 초기화합니다.
🤖 6. LLM 환경 설정 및 창의성 가이드
LM Studio, Ollama, vLLM, OpenAI 호환 로컬/원격 서버와 유연하게 연동됩니다.
• API Base URL: 로컬 또는 원격 LLM 서버 엔드포인트 (예: http://127.0.0.1:1234).
• Temperature 설정:
- 0.0 ~ 0.3 (추천): 정밀하고 일관된 답변, 코드 작성 및 MCP 도구 호출에 최적
- 0.4 ~ 0.7: 균형 잡힌 자연스러운 대화
- 0.8 ~ 1.5+: 창의적 발상 및 아이디어 브레인스토밍
