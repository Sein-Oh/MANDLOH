# MANDLOH
만들오의 자료공방 입니다.  
내용은 [블로그]에 담고 있습니다.  
* * *

흩어져 있던 개인 저장소 21개를 이 저장소 하나로 통합했습니다. 파일만 옮겼고 커밋 기록은 각 원본 저장소에 남아 있습니다.

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `3D Print` | 3D 프린팅 모델·G-code (Custom Lego technic motor, 메카넘 휠, MG90S 부품 등) |
| `AI` | 모델·데이터셋 (onnxjs, teachablemachine, UNET, image_classifier 등) |
| `AI_Agent` | AI 에이전트 CLI, MCP 서버 |
| `Javascript` | 웹 기반 프로젝트 (AI_Client, Tfjs, opencvjs, WebRTC, p5js, Node 등) |
| `MCU` | ESP32, MicroBit 펌웨어와 웹 제어 페이지 |
| `Project` | 완성된 프로젝트 (LinW, Object detection, 만들오토 웹사이트 등) |
| `Python` | 파이썬 예제 (GUI, Flask, 크롤링 등). `_legacy`는 예전 저장소에서 옮겨 온 미분류 코드 |
| `tmm` | 기타 |
