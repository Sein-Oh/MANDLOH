| `keras_torch` | Keras·PyTorch 학습 코드 (UNET, MNIST, YOLOv5 torch 등) |
| `tfjs` | 브라우저 TensorFlow.js 예제 (coco_ssd, tiny-yolo, yolov5, UNET 등) |

| `browser_ml` | Teachable Machine, ONNX.js, MobileNet, Pyodide/PyScript |
| `models` | 학습된 YOLOv5 웹 모델 가중치 |
| `object_detection` | Cloud Annotations, Roboflow 객체 탐지 |
