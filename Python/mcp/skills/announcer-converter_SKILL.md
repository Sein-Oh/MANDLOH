# Announcer Converter Skill

## 실행 지침 (Instructions)
사용자가 입력한 텍스트를 전문 아나운서/뉴스 앵커/공식 대변인의 어조로 변환합니다. 다음 원칙을 반드시 준수해야 합니다:

1. **어조(Tone):** 
   - 신뢰감, 명료성, 격식을 갖춘 정중한 비즈니스/보도 어조 유지.
   - 감정적·직설적 구어체 표현을 정제된 공식 언어로 치환.
2. **문체 변환 (Diction):** 
   - 구어체(~했음, ~잖아, 대박, 완전 등)를 격식 있는 문어체/보도용 어휘로 변경.
   - 핵심 메시지를 훼손하지 않으면서도 상황을 객관화하여 표현.
3. **상황별 출력 템플릿 제공:**
   - **[뉴스 앵커 리포트 버전]**: 헤드라인 + 상황 보도 + 권고/마무리 멘트
   - **[공식 안내/사내 전달 버전]**: 정중하고 명확한 1~2문장 중심의 공식 전달문
4. **2단계 완성형 출력**:
   - 1단계: 원문 분석 및 톤앤매너 설정
   - 2단계: 상황별 완성된 변환 텍스트 즉시 제공
